# Lu Zou Academic Homepage

A static academic homepage for GitHub Pages.

## Structure

- `index.html`: page content
- `assets/css/style.css`: page style
- `assets/js/main.js`: section navigation behavior
- `img/`: portrait and publication figures, preserving the current filenames

## Deployment

Push all files in this directory to the root of the `luzzou.github.io` repository and enable GitHub Pages from the repository settings.
