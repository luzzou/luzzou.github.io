# Lu Zou Academic Homepage

A responsive, single-page academic website designed for GitHub Pages.

## Deploy

1. Replace the files in the root of the `luzzou.github.io` repository with this project.
2. Commit and push to the default branch.
3. In GitHub **Settings → Pages**, select **Deploy from a branch**, then choose the default branch and `/ (root)`.

## Update content

- Main content: `index.html`
- Styling: `assets/css/style.css`
- Interactions: `assets/js/main.js`
- Publication illustrations: `assets/img/`
- Existing paper figures and portrait: `picture/`

The site has no build dependency and can also be previewed by opening `index.html` locally.
